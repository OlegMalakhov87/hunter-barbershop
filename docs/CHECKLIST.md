# Чек-лист Hunter

Дата аудита: 2 ноября 2026 года. Отметка означает проверку приложения, пустой пункт требует действий перед публикацией либо проверки на рабочем сервере. Подробности и границы проверки: `SECURITY_AUDIT.md`.

## Безопасность

- [x] Закрытые маршруты требуют действующий Bearer-токен; cookie не даёт доступ.
- [x] Проверяются подпись, алгоритм, назначение и срок JWT; выход отзывает сеанс.
- [x] Токен находится только в памяти страницы; ответы админки не кэшируются.
- [x] В .env хранится хеш scrypt со случайной солью; открытый пароль при запуске запрещён.
- [x] Есть команда скрытого ввода и разового перевода прежнего пароля без вывода секретов.
- [x] Ограничены неудачные входы, отзывы, загрузки и общий поток API.
- [x] SQL выполняется через Sequelize; нет пользовательских команд, eval и исполняемых шаблонов.
- [x] Входные данные валидируются; в модели попадают только разрешённые поля.
- [x] Тексты экранируются при выводе, JSON в HTML безопасен, CSP использует nonce.
- [x] CORS ограничен своим origin; изменения с чужим Origin запрещены.
- [x] Helmet, размеры запросов, HTTP-тайм-ауты и граница доверия прокси настроены.
- [x] Загрузки доступны только админу; проверяются MIME, сигнатура, декодирование, размер и число пикселей.
- [x] Фото пересоздаются как WebP без метаданных, имена случайные, скрипты из uploads не отдаются.
- [x] Ограничены одновременные преобразования фото; старые общие файлы не удаляются преждевременно.
- [x] Зависимости закреплены lock-файлом; уязвимый uuid заменён исправленной версией.
- [x] Журнал не содержит паролей, JWT, тел форм, SQL и персональных текстов.
- [x] `.env` и база находятся вне публичной папки; секреты и данные исключены из Git.
- [ ] На хостинге настроены HTTPS, закрытые порты, минимальные доступы и поддерживаемая Node.js.
- [ ] Настроены ротация журналов, контроль ошибок, места на диске и оповещения.
- [ ] Настроены внешние резервные копии, выполнено пробное восстановление.
- [ ] Заполнены юридические документы, проверены сроки хранения и действия при обращении об удалении данных.

## Данные и архитектура

- [x] Восемь текущих моделей; собственной записи и таблицы bookings нет.
- [x] Нет автоматических миграций, force/alter и наполнения демонстрационными записями.
- [x] Первая инициализация создаёт базу; повторная и новый процесс сохраняют данные.
- [x] Несовместимая схема останавливает запуск без удаления записей.
- [x] Рабочая схема сверена с моделями; обновление не требует удаления рабочей базы.
- [x] Маршруты, контроллеры, общие сервисы и проверки разделены.
- [x] Общие функции используются для полей каталога, документов, контактов и удаления фото.
- [x] Убраны старые миграции, автозаполнение, лишние состояния и неиспользуемые стили.
- [x] CSS разбит на пронумерованные разделы с оглавлением, адаптация собрана в конце.
- [x] Добавлены единое форматирование, русские комментарии и документация.
- [x] Перед запуском и тестами проверяется Node.js 24, до загрузки нативных модулей.

## Функции и приёмка

- [x] Автоматические проверки услуг с двумя ценами, контактов и проверяемых ссылок.
- [x] Автоматические проверки отзывов, статистики, версий и отдельных согласий.
- [x] Пять успешных отзывов с одного IP за десять минут, шестой отклоняется; ошибки заполнения лимит не расходуют.
- [x] Отключение запущенной аналитики предупреждает о потере незавершённого отзыва; отмена сохраняет ввод.
- [x] Автоматические проверки загрузки, преобразования и удаления фото.
- [x] Автоматические проверки политики, записи и условного подключения аналитики.
- [x] Локальный Chrome: 320, 390, 768, 844, 1024, 1440 px и поворот экрана, без переполнения страницы.
- [x] Локальный Chrome: меню, список с клавиатурой, формы и сброс, просмотр фотографий, вход и выход.
- [x] Локальная админка: загрузка в WebP, изменение фото, юридическая форма, отсутствие горизонтального переполнения.
- [x] Условное подключение счётчика и запись через имитацию внешних сервисов; ошибок JavaScript приложения нет.
- [ ] Перед публикацией сверены настоящие цены, мастера, фото, телефон, адрес и часы.
