# Hunter

Сайт барбершопа с каталогом услуг, мастерами, галереями, отзывами и панелью управления. Онлайн-запись работает через YCLIENTS.

Интерфейс использует HTML, CSS и JavaScript без сборки. Сервер использует Node.js, Express, SQLite, Sequelize и Sharp.

## Требования

Нужны **Node.js 24.x** и npm. Версия Node.js указана в `.nvmrc` и `package.json`. Проверка версии выполняется перед запуском приложения и тестов.

SQLite работает внутри приложения. Отдельный сервер базы данных не требуется. Зависимости устанавливаются на той системе, где работает приложение: `node_modules` не переносится между Windows и Linux.

## Локальный запуск

Команды выполняются из корня проекта.

1. Установите зависимости:

   ```bash
   npm ci
   ```

2. Создайте файл настроек:

   ```bash
   cp .env.example .env
   ```

   В PowerShell: `Copy-Item .env.example .env`. Файл `.env` содержит секреты и не входит в Git.

3. Заполните обязательные параметры:

   ```dotenv
   SITE_URL=http://localhost:3001
   ADMIN_LOGIN=local-admin
   JWT_SECRET=ЗАМЕНИТЬ_СЛУЧАЙНЫМ_СЕКРЕТОМ
   ```

   Для `JWT_SECRET` используйте результат команды:

   ```bash
   node -e "console.log(require('node:crypto').randomBytes(48).toString('hex'))"
   ```

4. Задайте пароль администратора:

   ```bash
   npm run admin:password
   ```

   Команда запрашивает пароль дважды, скрывает ввод и записывает `ADMIN_PASSWORD_HASH` в `.env`.

5. Запустите приложение:

   ```bash
   npm run dev
   ```

Главная доступна по `http://localhost:3001`, панель управления по `http://localhost:3001/admin`. Команда `npm start` запускает приложение без наблюдения за файлами.

При отсутствии базы приложение создаёт пустой файл `data/hunter.sqlite` и таблицы. Содержимое заполняется через админку. При наличии файла приложение использует его без сброса записей.

## Переменные окружения

Образец конфигурации находится в [`.env.example`](.env.example). После изменения настроек требуется перезапуск приложения.

Обязательные параметры:

- `SITE_URL`: адрес сайта с `http://` или `https://`, без пути, параметров и фрагмента. Используется для canonical, карты сайта и проверки Origin.
- `ADMIN_LOGIN`: логин администратора длиной 6–100 символов.
- `ADMIN_PASSWORD_HASH`: хеш пароля, который записывает `npm run admin:password`. Длина вводимого пароля составляет 12–100 символов.
- `JWT_SECRET`: случайный секрет длиной не менее 32 символов.

Параметры запуска:

- `HOST`: адрес прослушивания, по умолчанию `127.0.0.1`.
- `PORT`: порт HTTP-сервера, по умолчанию `3001`.
- `NODE_ENV`: режим Express; для рабочего сервера используется `production`.
- `TRUST_PROXY`: `false` для прямого запуска, `loopback` для Nginx на той же машине. Значение `true` также означает доверие только локальному прокси.
- `DB_STORAGE`: путь к SQLite, по умолчанию `data/hunter.sqlite`. Относительный путь считается от корня проекта; `:memory:` используется для тестов.

Необязательные параметры:

- `YCLIENTS_BOOKING_URL`: HTTPS-ссылка на форму YCLIENTS. Адрес вида `https://n123456.yclients.ru/` включает официальный виджет. Пустое значение направляет кнопку записи к блоку контактов.
- `YANDEX_METRIKA_ID`: номер счётчика. Счётчик и карта подключаются только после согласия посетителя.
- `UTM_SOURCE`, `UTM_MEDIUM`, `UTM_CAMPAIGN`: метки публичных ссылок контактов. Добавление меток включается через `UTM_SOURCE`.

Телефон и ссылки на способы связи хранятся в SQLite и редактируются через админку.

## Структура проекта

```text
client/
  pages/                HTML-шаблоны
  public/               CSS, JavaScript, шрифты и изображения
server/
  app.js                сборка приложения и управление запуском
  config/               настройки окружения и приложения
  routes/               маршруты страниц и API
  controllers/          HTTP-обработчики
  services/             прикладная логика
  middleware/           авторизация, проверки и обработка ошибок
  utils/                общие HTTP-инструменты
  models.js             модели Sequelize
  database.js           подключение и инициализация SQLite
  scripts/              команды пароля и изменения схемы
  *-default.txt         исходные юридические тексты
test/                   автоматические проверки
docs/                   техническая документация
data/                   файл SQLite
```

## Команды разработки

```bash
npm test
npm run format:check
npm run format
```

Тесты используют временные базы и удаляют собственные файлы. Prettier задаёт единое форматирование исходников и документации.
